Tentang Saya 💫

Kenalan sedikit dengan pembuat website Disney World.

Halo, saya Hasna! 👋

Perkenalkan, nama saya Hasna. Saya adalah seorang pelajar yang sedang mempelajari berbagai hal tentang teknologi dan pembuatan website.

Website Disney World ini dibuat sebagai salah satu proyek untuk belajar membuat website menggunakan HTML dan CSS melalui Visual Studio Code.

Saya memilih tema Disney karena film-film animasi seperti Zootopia, Frozen, dan Tangled memiliki cerita yang menarik serta karakter yang mudah dikenali.

Melalui proyek ini, saya belajar bagaimana membuat halaman website, mengatur tampilan menggunakan CSS, menambahkan gambar, membuat navigasi, dan menyusun informasi agar lebih mudah dibaca.

Tentang Website

💻 Teknologi

Website ini dibuat menggunakan HTML dan CSS. Visual Studio Code digunakan sebagai aplikasi untuk menulis dan mengedit kode.

🎬 Tema

Tema website adalah film animasi Disney, khususnya Zootopia, Frozen, dan Tangled.

🎯 Tujuan

Website dibuat untuk belajar membuat tampilan website sederhana dan menyusun informasi dalam beberapa halaman.

Yang Saya Pelajari 🌷

Dalam membuat website ini, saya belajar tentang struktur HTML, penggunaan CSS, pengaturan warna dan layout, penggunaan gambar, pembuatan navigasi antarhalaman, serta cara membuat tampilan website yang lebih menarik dan nyaman dilihat.
